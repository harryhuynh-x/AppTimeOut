How to use
AppTimeOut

Four simple steps to take control of your screen time — and actually stick to it.

Step 1

Create a schedule lock.

Choose the lock type that fits your routine. Both kick in instantly once activated.

  • Timer Lock — use + / − to set a duration, tap Start Lock. Lifts automatically when time is up.
  • Schedule Lock — pick days and time slots, toggle Weekly to repeat. Set it once and let it run.
💡 Free: Timer Lock + up to 5 days / 4 slots  |  Pro: All 7 days · unlimited slots

Step 2

Set up your block list.

Tap the ⋯ menu → Manage Blocks and add the apps and websites you want to restrict. You can block social media, games, news — anything that pulls your focus.

  • Enable Screen Time Access and Safari Extension when prompted on first launch
  • Tap Add App to pick from the iOS app picker
  • Tap Add Website and type a domain like instagram.com
  • Swipe left to rename or delete any item
💡 Free: Up to 3 apps & 3 websites  |  Pro: Unlimited apps & websites

Step 3 — Pro

Add a buddy.

Struggling with "just 5 more minutes"? Buddy Lock hands the unlock key to someone you trust — so willpower is no longer the only thing standing between you and your phone.

  • Go to ⋯ menu → Manage Buddies → Add Buddy
  • Enter your buddy's email — they'll receive a verification code to confirm
  • Enable the Buddy Lock toggle on any lock card
  • Add up to 3 buddies — friends, family, or a study partner

Step 4

Start a lock.

Once your block list is ready and your buddy is set, activate a lock. Blocked apps and websites are restricted immediately — and stay that way.

  • Tap Start Lock on the Timer or Schedule card
  • The lock activates instantly across all blocked apps and websites
  • With Buddy Lock on, only your buddy's code can end it early

Step 5 — Pro

Unlock with a code.

Need to end a lock early? Tap Request Unlock Code — your buddy receives a 4-digit code by email. Enter it in the app to unlock. Codes expire after 24 hours.

  • Tap Unlock with Buddy Code on the active lock card
  • Ask your buddy for the code they received by email
  • Enter the 4-digit code to release the lock

Common questions

Why aren't my apps being blocked?

Make sure you've added apps to your block list before starting a lock, and that Screen Time permission was granted on first launch.

Does blocking work if I close the app?

Yes — blocking runs through iOS's Screen Time system, completely independent of the app.

Can I unlock early without a buddy?

Yes, for Timer Lock and Schedule Lock without Buddy Lock enabled. Once Buddy Lock is on, only your buddy's code can end it early.
