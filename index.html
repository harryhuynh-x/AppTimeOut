Purpose

AppTimeOut helps you reduce digital distractions by blocking selected apps and websites — social media, messaging apps, entertainment platforms, and more.

The core idea is simple: when you decide to lock your distracting apps, you can keep the lock fully self-controlled or add an accountability buddy who must provide an unlock code if you want to end the lock early.

This buddy-assisted unlock system encourages healthier habits, reduces impulsive app use, and supports long-term focus and wellbeing.

How It Works

  • Choose what to block: Select the apps and websites you find most distracting.
  • Set a timer or schedule: Lock for a quick duration or set recurring daily blocks.
  • Self-lock option: Keep full control — lock clears automatically when time is up.
  • Buddy Lock option: Require a trusted buddy's code to end the lock early.

Step-by-Step

1 Choose What to Block

  • Tap the ⋯ menu (top-right) → Manage Blocks.
  • Tap Allow Screen Time Access if prompted — this is required for blocking to work.
  • Under Apps, tap Add App and pick from the iOS picker.
  • Under Websites, tap Add Website or Add Manually to type a domain (e.g. instagram.com).
  • For website blocking to work in Safari, tap Enable Safari Extension → turn on AppTimeOut Blocker in the iOS Settings that open.
  • Swipe left on any item to Rename or Delete it.

2 Timer Lock (Free & Pro)

  • Use + / − to set a duration, then tap Start Lock.
  • Blocked apps and websites are immediately restricted.
  • The lock lifts automatically when the timer expires.

3 Schedule Lock (Free & Pro)

  • Tap the day circles to pick which days to block.
  • Tap Add Slot and set a start and end time.
  • Toggle Weekly on to repeat every week automatically.
  • Enable Self-Lock to activate the schedule.
💡 Free: Up to 5 days/week · 4 slots  |  Pro: All 7 days · unlimited slots

4 Buddy Lock Pro only

  • Go to ⋯ menu → Manage Buddies → Add Buddy.
  • Enter your buddy's email — they'll receive a 4-digit unlock code.
  • On the Schedule card, enable the Buddy Lock toggle.
  • To unlock early, tap Unlock with Buddy Code and ask your buddy for their code.

Common Questions

Why aren't my apps being blocked?
Make sure you've added apps to the block list before starting a lock, and Screen Time permission was granted on first launch.

Does blocking work if I close the app?
Yes — blocking runs through iOS's Screen Time system, independently of the app.

Can I unlock early without a buddy?
Yes, for Timer Lock and Schedule Lock. With Buddy Lock enabled, you need your buddy's code to unlock early.
