How to block distracting apps on Android

Android makes it easy to open anything at any time. Here is how to put a block screen in front of the apps that pull you in, for a focus session or on a repeating schedule.

Step by step

  1. Install AppTimeOut from Google Play (free to start).
  2. Turn on the Accessibility Service when prompted. Android requires this permission for any app that shows a block screen over other apps. See below for what it is used for.
  3. Choose what to block. Add the apps and websites you want out of reach. The free plan covers 3 apps and 3 websites; Pro removes the limit.
  4. Start a lock. Run a Timer for a focus stretch, or create a Schedule for the days and hours you want protected.

About the Accessibility permission

On Android, AppTimeOut uses the Accessibility Service to notice which app is in the foreground and, in a supported browser, which address is open, only to decide whether to show the block screen. This is processed on your device in real time. It is not collected, stored, sold or shared. You can turn the permission off in Android Settings at any time, which also turns blocking off. Timer, schedule or buddy?

  • Timer Lock — block now, for a duration you choose.
  • Schedule Lock — set days and time slots once; it repeats weekly.
  • Buddy Lock — a friend holds the unlock code, so you cannot simply switch the lock off in a weak moment.
