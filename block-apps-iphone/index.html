How to block distracting apps on iPhone

Willpower is a bad plan when the app is one tap away. The reliable way to stay off distracting apps is to make them unavailable for a while. Here is how to do it on an iPhone in a couple of minutes.

What you need

AppTimeOut (free to start) and an iPhone running iOS 16.6 or later. Blocking is built on Apple's own Screen Time system, so it keeps working even when you close the app.

Step by step

  1. Install AppTimeOut and allow Screen Time access when asked. This lets iOS, not the app, put the block screen in front of the apps you pick.
  2. Choose what to block. Open Manage Blocks and add the apps (and websites) that pull you in. The free plan covers 3 apps and 3 websites; Pro removes the limit.
  3. Turn on the Safari extension in Settings → Safari → Extensions so websites you listed are blocked in Safari too.
  4. Start a lock. Use the Timer for a focused stretch (for example 25 minutes), or set a Schedule for the hours you usually scroll, such as 9–5 on weekdays.

Timer or schedule?

Timer Lock is for right now: pick a duration and the apps are blocked until it ends. Schedule Lock is for habits: set the days and time slots once and it enforces itself every week.
